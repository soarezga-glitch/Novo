# Salmo 91 – Versão de leitura para a Aline

## Como ler as marcações

| Marca | O que fazer |
|---|---|
| `/` | Respiração curta, meio segundo. Só respira e segue. |
| `//` | Pausa de verdade, 1 a 2 segundos. Deixa o silêncio trabalhar. |
| `→` | **Emenda sem parar**, mesmo que pareça o fim de uma frase. |
| `...` | A voz fica no ar, sem fechar a frase, como quem vai contar um segredo. |
| **PALAVRA** | Dá peso à palavra: mais lenta e mais firme. Não precisa falar mais alto. |
| `(↓)` | Baixa a voz, mais íntima, quase um segredo. |
| `(↑)` | Mais energia e curiosidade, como quem descobriu algo. |
| `(devagar)` | Diminui o ritmo até a próxima indicação. |
| `(normal)` | Volta ao ritmo de conversa. |
| `(sorrindo)` | Fala sorrindo. O sorriso aparece na voz. |

**Regras de ouro**
1. **Quebra de linha não é pausa.** Só pausa onde tem `/` ou `//`.
2. **Converse com UMA pessoa.** Imagina uma amiga sentada no sofá, não uma plateia.
3. **Os versículos entre aspas vão mais devagar e mais baixo**, como quem lê em oração.
4. **Nas listas ("Quando... Quando... Quando..."), cada item vai um pouco mais lento e mais baixo que o anterior.** Isso dá peso à sequência.
5. **No padrão "Não isso. Não aquilo. Mas isto."**, os dois "Não" vão rápidos e a última parte vai devagar e firme.
6. **Perguntas sobem no final.** Depois de uma pergunta, sempre faz a pausa `//` para a pessoa pensar.
7. Antes de gravar um capítulo, **lê em voz baixa uma vez**, para saber para onde a frase vai.

## Abertura

(devagar, ↓) Existe um salmo que as pessoas leem / quando estão com **medo**. //

Quando o médico liga / com uma notícia ruim. / Quando o filho / ainda não chegou em casa. / Quando a noite... / parece **longa demais**. //

(normal) Esse salmo é o **91**. / E ele esconde um detalhe que quase ninguém percebe. → Um detalhe tão importante que, quando o diabo tentou usar esse salmo contra Jesus... // (↓) ele **pulou uma parte**. //

(↑) Hoje você vai descobrir qual parte foi essa. / E no final desse salmo existe uma frase / que muda **tudo** o que vem antes dela. //

(normal) Mas pra chegar lá, → você primeiro precisa entender por que tanta gente lê o Salmo 91 / do **jeito errado**. //

(sorrindo) Eu sou a **Aline**. / E aqui a gente abre a Bíblia **devagar**. / Sem pressa. / Versículo por versículo. //

Então pega um café, → ou se acomoda aí no sofá. / Porque hoje a gente vai entrar / num **esconderijo**. //

## O esconderijo

(devagar) O salmo começa assim: / (↓) "Aquele que habita no esconderijo do Altíssimo, / à sombra do Onipotente / descansará." //

(normal) Repara numa palavra: / **habita**. //

O salmo não diz "aquele que **visita**". / Não diz "aquele que **passa** de vez em quando". / Diz aquele que **habita**. // Que **mora**. / Que fez daquele lugar / a sua **casa**. //

(↑) E aqui está o primeiro segredo. / (normal) Muita gente trata o Salmo 91 como um **amuleto**. → Deixa a Bíblia aberta nessa página, → lê em voz alta quando o medo aperta. / E não tem nada de errado em buscar a Deus na hora do medo. //

Mas a promessa desse salmo não é para quem **lê** o esconderijo. / (devagar) É para quem **mora** nele. //

(normal) E repara que a recompensa de quem mora ali é uma só palavra: / **descansará**. // Não "lutará". → Não "se esforçará". / (devagar, ↓) **Descansará**. //

Talvez você esteja cansado / de lutar **sozinho**. / O salmo começa te convidando a parar de lutar sozinho, → e a morar perto de Deus. //

(↑) Mas **espera**. / Antes de entrar nesse esconderijo, → você precisa saber **quem** está lá dentro. / (normal) Porque no versículo seguinte, Deus é chamado de um jeito que só aparece no **hebraico**. / (↓) E esse detalhe vai voltar no final do vídeo... / de um jeito que você **não espera**. //

## Os quatro nomes

(devagar, ↓) "Direi do Senhor: / Ele é o meu Deus, / o meu refúgio, / a minha fortaleza, / e nele confiarei." //

(normal) E é aqui que aparece aquele detalhe do hebraico, → a língua em que esse salmo foi escrito. //

Nos dois primeiros versículos, Deus é chamado por **quatro** nomes diferentes. / Cada nome revela uma coisa diferente sobre Ele. / (↓) E o último... / é o mais poderoso de todos, → apesar de ser o mais simples. //

(devagar) **Altíssimo**. / Em hebraico, *Elyon*. / O Deus que está acima de tudo. → Acima de qualquer problema que você esteja enfrentando. //

**Onipotente**. / *Shaddai*. / O Deus que pode tudo. / Nada é grande demais para Ele. //

**Senhor**. / O nome mais sagrado de Deus, → aquele que Ele revelou a Moisés na sarça ardente. / O Deus que é fiel à sua palavra. //

(↓) E por último... / **meu Deus**. //

(normal) Repara no que acontece. / Os três primeiros nomes falam de quem Deus **é**. / Grande, / poderoso, / fiel. / Mas o quarto nome tem uma palavra a mais: // **meu**. //

(devagar) O Deus que está acima de tudo, / que pode tudo, / que nunca falha... / é também **o meu** Deus. // (normal) O salmista não está falando de um Deus distante. / Está falando de alguém que ele conhece / pelo **nome**. //

(↑) Mas conhecer esse Deus não quer dizer que o perigo deixa de existir. / E o versículo seguinte fala de um perigo muito pior do que aquele que a gente vê. // (↓) Um perigo **escondido**. //

## O laço escondido

(devagar, ↓) "Porque ele te livrará do laço do passarinheiro, / e da peste perniciosa." //

(normal) Na época da Bíblia, existia um caçador que era o pesadelo dos pássaros: / o **passarinheiro**. / E o mais assustador nele não era a arma. // (↓) Era o **jeito** como ele caçava. //

(normal) Ele não caçava com flecha. / Ele preparava um **laço**, → uma armadilha escondida no chão, / e **esperava**. //

(devagar) O pássaro nunca via o laço. / Ele só via a comida. / (↓) Quando percebia o perigo... / já era **tarde**. //

(normal) Deus está dizendo aqui: / "Eu te livro dos perigos / que você nem consegue **ver**." //

(devagar) Quantas vezes você atrasou cinco minutos / e não sabe do que foi livrado? // Quantas portas se fecharam e você chorou, → sem saber que do outro lado / tinha um laço esperando? //

(↓) Às vezes a maior proteção de Deus / é aquela que a gente **nunca** fica sabendo. //

(↑) Mas e quando o perigo **não** está escondido? / Quando a tempestade já chegou, → e você está bem no meio dela? // (normal) O versículo 4 responde com uma imagem que Deus escolheu para falar de si mesmo. / (↓) E é uma imagem / que **ninguém** esperaria. //

## Debaixo das asas

(normal) O Deus Altíssimo, → o Onipotente, / poderia se comparar a um **rei**. / A um **guerreiro**. / A um **exército**. // (↓) Mas aqui Ele escolhe ser comparado / a uma **ave**. //

(devagar, ↓) "Ele te cobrirá / com as suas penas." //

(normal) Quando vem a tempestade, → a ave mãe não manda os filhotes se defenderem sozinhos. / Ela abre as asas. / E **cobre**. / (devagar) A chuva cai em cima **dela**, / e não deles. //

E repara: / debaixo das asas, → os filhotes não veem a tempestade. / (↓) Eles só escutam / o coração da mãe. //

(devagar) Talvez a sua tempestade ainda não tenha passado. / Mas você pode estar debaixo das asas, → escutando o coração de Deus, / enquanto ela passa. //

(↑) E séculos depois, → alguém usou exatamente essa mesma imagem. // (↓) **Chorando**. //

(normal) Foi **Jesus**. / Olhando para Jerusalém, Ele disse: / (devagar, ↓) "Quantas vezes quis eu ajuntar os teus filhos, / como a galinha ajunta os seus pintos / debaixo das asas." //

(↓) O convite das asas / ainda está **aberto**. //

(normal, sorrindo, um pouco mais rápido) Se esse salmo está falando com você hoje, → deixa seu like, → se inscreve no canal, → e escreve nos comentários: / "Eu estou debaixo das asas." / Eu leio cada um. //

(↑) Porque agora o salmo vai fazer uma promessa tão forte... / que muita gente tem **medo** de acreditar nela. //

## Mil cairão ao teu lado

(devagar, ↓) "Não terás medo do terror de noite / nem da seta que voa de dia." //

(normal) O salmo continua listando os medos. / O terror da **noite**. / A seta que voa de **dia**. / A peste que anda na **escuridão**. //

Repara que ele cobre o dia **e** a noite. / (↓) Não existe hora / em que você esteja fora do cuidado de Deus. //

(↑) E aí vem um dos versículos mais fortes: / (devagar) "Mil cairão ao teu lado, / e dez mil à tua direita, // mas não chegará **a ti**." //

(normal) Mas cuidado com uma coisa. / O Salmo 91 **não** promete uma vida sem problemas. / Gente fiel adoece. / Gente fiel perde pessoas que ama. / (↓) O próprio Jesus / sofreu. //

(↑) Então o que esse salmo promete? //

(↓) Guarda essa pergunta. / Porque a resposta está no final. / E ela vem da boca / do próprio **Deus**. //

(normal) Mas antes, → a gente precisa voltar para aquele mistério do começo. / (↓) O dia em que o próprio diabo / abriu o Salmo 91. //

## O salmo que o diabo citou

(devagar, ↓) "Porque aos seus anjos dará ordem a teu respeito, / para te guardarem em todos os teus caminhos." //

(normal) Jesus estava no deserto havia quarenta dias, → em jejum. / (devagar) Sozinho. / Com fome. / Fraco. // (↓) E foi exatamente nesse momento / que o diabo **apareceu**. //

(normal) E numa das tentações, → ele levou Jesus até o ponto mais alto do templo e disse: / "Se tu és o Filho de Deus, → lança-te daqui abaixo." //

E aí o diabo fez uma coisa que ele não tinha feito até ali. // (↓) Ele **citou a Bíblia**. //

(↑) E sabe qual texto ele escolheu? // (↓) O Salmo **91**. //

(normal) Ele disse: / "Está escrito: → aos seus anjos dará ordens a teu respeito, → e eles te tomarão nas mãos, / para que não tropeces em alguma pedra." //

Mas compara com o que o salmo **realmente** diz. //

(devagar) O salmo diz: / "para te guardarem / em **todos os teus caminhos**." // (↓) O diabo **cortou** essa parte. //

(↑) Por quê? // (normal) Porque a proteção de Deus é para quem anda nos caminhos **de Deus**. / Não é para quem se joga do alto do templo / para **testar** se Deus vai segurar. //

Jesus respondeu: / (devagar, firme) "Também está escrito: / não tentarás o Senhor teu Deus." //

(↑) Mas o corte não foi o único detalhe. / Tem uma coisa ainda mais impressionante. // (↓) E ela está no versículo / que ele **não leu**. //

(normal) O diabo parou de citar no versículo **doze**. / Sabe o que diz o versículo **treze**, logo depois? //

(devagar, firme) "Pisarás o leão e a cobra. / Calcarás aos pés / a **serpente**." //

(↓) O diabo parou exatamente um versículo antes / da parte que fala da **derrota** dele. //

(devagar) Ele conhecia o Salmo 91. // Ele só não leu / até o **fim**. //

(↑) Mas a gente vai ler. / Porque é justamente no fim → que está a frase que eu te prometi no começo do vídeo. //

## A voz que muda

(↓) E agora a gente chega no detalhe mais emocionante desse salmo. //

(normal) Até aqui, quem fala é o salmista. → Ele fala **sobre** Deus. / Mas no versículo quatorze... // a voz **muda**. //

(↓) Quem começa a falar / é o próprio **Deus**. //

(devagar, ↓) "Pois que tão encarecidamente me amou, / também eu o livrarei. / Pô-lo-ei num alto retiro, / porque conheceu o meu nome." //

(normal) Repara no motivo. / Não é "porque ele era perfeito". → Não é "porque ele nunca errou". / (devagar) É porque ele **me amou**. / Porque ele conheceu / o meu **nome**. //

(↑) Lembra dos quatro nomes lá do começo? // (↓) É esse o nome / que Deus quer que você conheça. //

(devagar, ↓) "Ele me invocará, / e eu lhe responderei; / estarei com ele na angústia; / livrá-lo-ei, / e o glorificarei." //

(normal) E aqui está a resposta da pergunta que eu deixei no meio do vídeo. //

(devagar, ↓) "Estarei com ele / **na angústia**." //

(normal) Deus não diz "você nunca vai passar por angústia". / Ele diz: / (devagar) "Quando a angústia vier, / **eu vou estar lá** com você." //

(↓) Essa é a verdadeira promessa do Salmo 91. / Não é uma vida sem tempestade. // É nunca mais enfrentar uma tempestade / **sozinho**. //
